## 1. 审查发现（动机）

对真实产出的对抗性审查发现三个产出没有兑现定位、一条链路静默失败：

1. **笺注只是"字体稍大的撷要"**：3 小时课的笺注仅 4,820 字（撷要 3,522 字），与撷要共用同一提示词、同一七节结构，唯一区别是一个形容词（"篇幅详尽"）。课堂 90% 的论证过程、案例细节、现场交锋消失。
2. **脉络是"七座孤岛"**：ROOT 节点无连线、7 个 subgraph 之间零跨组边——课程主线逻辑完全缺失，代码不校验连通性。
3. **实录三个内伤**：碎片问答被压成独白（分块无上下文传递）；ASR 乱码原样保留（"拿不准保留原文"红线的副作用）；5 万字无任何结构锚点。
4. **笔记照片链路静默失败**：两个上传了照片的项目，转录全部失败且失败原因被吞掉，产出里没有任何笔记内容，用户不知情；转录结果在 UI 中永远不可见。
5. **"对你的启发"靠虚构**：无用户画像时模型自己编身份。

## 2. 深度笺注（本版核心）

### 2.1 架构

```
纲目(N阶段) ──贪心打包──► 6-11 个单元（切片≤12K字 或 ≤6阶段/单元）
每单元输入：该时段实录切片 + 单元纲目条目 + 全课目录 + 学员画像 + 补充背景
单元并行生成 → 覆盖率闸门（每阶段必须成节，缺→带反馈重试→仍缺报错不落盘）
→ 导读调用（合理性校验，两次不合格则省略导读）
→ 确定性拼装（部分标题原位回插、阶段按纲目序回放）→ 附录回填笔记照片转录
```

- 时段切片：实录新增确定性时间锚点（`#### ⏱ H:MM:SS`，取自分块起始时间戳），阶段时间区间 ↔ 锚点位置精确映射；老会话无锚点/无时间时退化为按阶段占比的比例切片。
- 解析/切片/分组在 `pipeline/deepnotes.py`（纯确定性、不调模型）；连通模型的流程在 engine。

### 2.2 反膨胀设计（长度由内容密度决定，无任何字数目标）

写进提示词的硬性规则：

- **证据绑定**：每个论点必须挂至少一条具体证据（摘引/数据/案例/论证步骤）；无证据的观点只能进一行「存而未证」，不得成段。
- **完整收录承诺**：该时段实录中出现的每个具体案例、数据、论断必须收录；离题闲谈可舍弃但须以「舍弃：…」显式列出。
- **套话禁令**：禁止"综上所述/意义重大/深刻启发"类空段；每段必须含至少一个具体事实。
- **固定微结构、空节即省**：核心论点 → 论证链 → 例证与数据（「」逐字摘引）→ 现场问答 → 承转；无内容的小节直接省略，禁止硬凑。
- **摘引逐字**：摘引必须逐字来自实录（可含 `[听不清]`/`[存疑]` 标记）。
- 画像只作侧重指引，不单独成节（"对你的启发"专属撷要，两产出真正分化；术语表也留在撷要）。

### 2.3 真实验证结果（赵龙凯 · 3 小时讲座）

- 旧笺注 4,820 字 → 新笺注约 2.8 万字（84KB），26 阶段全覆盖、161 处逐字摘引、导读精准勾勒课程主线。
- 密度抽查：阶段 18 把校友分享的"八段经历"逐条收录（每条带具体事实与摘引），`[存疑：…]` 正确用于拿不准的人名；阶段 17 主动发现并标注了"发言人身份错位"的转写疑点（熊总 vs 徐鹏），建议人工复核而非臆测——正是"笺注编纂者"应有的行为。
- 依赖变更：笺注 requires 从 `["transcript"]` 改为 `["transcript", "chapters"]`（骨架来自纲目）。

## 3. 实录改造

- **可读性优先分级红线**（取代"拿不准一律保留原文"）：能从上下文合理修复的必须修复；完全无法理解的片段整段替换为 `[听不清]`（不保留乱码、不编造）；数字/人名/公司名等事实红线保留，拿不准标 `[存疑：原文]`。
- **分块上下文传递**：每块携带前一原始块（去时间戳）结尾约 400 字作只读衔接上下文（并行执行下只能用原始块而非纠错结果）。
- **时间锚点小标题**：分块起始时间戳确定性插入 `#### ⏱ H:MM:SS`（约每 10-25 分钟一个），不靠模型。
- 验证：新实录 8 个锚点、1 处 `[听不清]`、9 处 `[存疑]`、74 处说话人标签，原碎片问答区内容完整。

## 4. 纲目与脉络

- **纲目篇章分组**：阶段之上新增 `## 第N部分：主题`（3-6 个宏观部分；短课堂可 2 个或不分）。验证产出：26 阶段 + 6 部分，主题划分清晰。
- **脉络连通性硬约束**：提示词强制 ROOT 连每个分支 + 跨分支主线关系边 + 分支按授课顺序；新模块 `pipeline/graphcheck.py` 确定性解析 mermaid 节点/边、校验无向连通性；不通过带孤立节点反馈返修一次，仍不通过报错不落盘（修订路径同样校验）。验证产出：41 节点 46 边单连通分量，一次通过。

## 5. 个人画像（全局 + 项目两级）

- 优先级：项目画像（meta.persona）> 全局画像（data/persona.txt）> 系统默认（"商学院学生"）。
- API：`GET/PUT /api/persona`；`PATCH /sessions/{sid}` 支持 persona；会话详情返回 `effective_persona`（含来源）。
- 前端：顶栏「个人画像」全局编辑入口；工作台"补充背景"卡片内项目级画像（占位符显示继承值）。
- 注入撷要/笺注/修订（实录/纲目/脉络不注入）；"对你的启发"必须基于画像、禁止虚构身份。
- 验证：矿业负责人画像下，启发一节产出"矿山资产即时间机器 / 探矿权作看涨期权 / 大宗商品需求的人口结构分析 / 跨文化矿产贸易谈判"等真实相关内容。

## 6. 笔记照片链路

- **失败原因透传**：逐张失败原因进入进度消息（不再只说"N 张失败"）；单张自动重试一次。
- **可见可校对**：新 API `GET /sessions/{sid}/notes`（三态：user 已校对 / cached 已识别 / none 未识别）、`PUT .../notes/{filename}`（保存人工校对，空串恢复自动）、`POST .../notes/{filename}/transcribe`（强制重识别，错误进 body）。用户校对落 `derived/notes/<文件>.user.md`，优先于机器缓存且不随图片 mtime 失效。
- 前端：图片行状态徽标 + 笔记面板（查看/编辑/保存校对/恢复自动/重新识别；用户校对生效时重新识别的机器结果不自动覆盖）。
- **真实根因修复**：用户照片 `.jpg` 实为 PNG，按扩展名声明 media_type 被 Anthropic 400 拒绝——修复为按文件魔数嗅探真实类型 + 补装 Pillow（venv 缺装导致降级路径生效）。修复后手写板书完整识别成功，并作为附录进入笺注。

## 7. 真实验证中发现并修复的兼容性问题

端到端跑通真实生成的过程本身就是对抗性测试，抓到并修复了 5 个真实世界问题：

| 问题 | 修复 |
|------|------|
| 图片扩展名与内容不符（.jpg 实为 PNG）被 API 拒绝 | 魔数嗅探真实 media_type + 安装 Pillow |
| 新一代模型（经中转站）拒绝 `temperature` 参数（"deprecated"） | 两个 provider 基类识别该错误后自动去参重试一次，并记在实例上不再发送 |
| 思考型模型的隐藏思考计入 max_tokens，小额上限（导读 800、撷要 4096、脉络 3000）在正文写完前被掐断 | 小额常量整体上调（导读 4000 / 撷要 8000 / 脉络 8000 / 笺注单元 16000），正文长度仍由提示词约束 |
| 中转站偶发丢失 system prompt，导读调用被模型反问"需要我做什么" | 指令在 user 消息中重复 + 引擎侧导读合理性校验（反问式/超长→重试→仍坏则省略导读，绝不放坏内容进产出） |
| 中转站偶发连接抖动打断单元生成 | 单元调用对瞬时故障重试一次（截断类错误直接上抛，不浪费重试） |

## 8. 质量闸门一览（本版新增）

| 产出 | 闸门 | 不通过时 |

## 10. 已知取舍

1. **笺注修订仍是整篇重生成**（上限 16000）：超长笺注修订可能触发截断报错（显式、不写坏数据）；按阶段定点修订留待后续。
2. **导读合理性校验是特征词启发式**：极端跑偏形态可能漏判，但拼装容忍无导读，风险有限。
3. **单元切片依赖纲目时间与实录锚点**：老会话（无锚点）走比例切片，精度略降，重新生成实录即恢复。
4. **成本**：笺注从 1 次调用变 12-13 次（11 单元 + 导读 + 可能的返修），时间约 8-10 分钟/3 小时课堂（已获用户确认）。
